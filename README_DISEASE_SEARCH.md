## 💡 The Core Issue & Solution

**Problem**: Inputting RSID into disease search → "RSID not found" error

**Solution**: 
- Use **DISEASE ASSOC** module for disease names
- Use **GENE VARIANT** module for RSIDs
- System now warns if you mix them up

**Learn more**: Read `docs/RSID_vs_DISEASE_EXPLAINED.md`
