## Common Questions

### Q: How do I know if a disease name is valid?
**A**: Use autocomplete or look it up on:
- MONDO: mondo.obo.org
- Orphanet: orphanet.org
- OMIM: omim.org

### Q: What if I get "no results"?
**A**: 
1. Check spelling
2. Try alternative name
3. Try shorter name
4. Use a disease from this list

### Q: Can I search by symptom instead?
**A**: No, use disease names only. Try disease name first, then look at phenotypes.

### Q: Are abbreviations ok?
**A**: Sometimes (like "CF" for Cystic Fibrosis), but full names work better.

### Q: Can I search multiple diseases at once?
**A**: No, search one at a time.

## Pro Tips

1. **Start Simple** → Use disease names from this list
2. **Use Full Names** → "Cystic Fibrosis" better than "CF"
3. **Check Spelling** → "Marfan" not "Marfanne"
4. **Try Variations** → If one doesn't work, try alternate name
5. **Use Autocomplete** → Let system suggest valid names
6. **Look at Results** → Each search shows tabs: Variants, Genes, Phenotypes, Drugs
