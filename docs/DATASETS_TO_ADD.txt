───────────────────────────────────────────────────────────────────────────────
  API ENDPOINTS AFTER ALL IMPLEMENTATIONS
───────────────────────────────────────────────────────────────────────────────

CLINVAR:
  GET  /api/clinvar/gene/{gene}              → Variants for gene
  GET  /api/clinvar/disease/{disease}        → Variants for disease

OMIM:
  GET  /api/omim/gene/{gene}                 → Diseases for gene
  GET  /api/omim/disease/{disease}           → Genes for disease

DRUGBANK:
  GET  /api/drugbank/target/{protein}        → Drugs for target
  GET  /api/drugbank/drug/{id}               → Drug details

DISGENET:
  GET  /api/disgenet/gene/{gene}             → Diseases for gene
  GET  /api/disgenet/disease/{disease}       → Genes for disease

COSMIC:
  GET  /api/cosmic/cancer/{type}             → Cancer mutations
  GET  /api/cosmic/gene/{gene}               → Gene mutations in cancer

GWAS:
  GET  /api/gwas/trait/{trait}               → GWAS associations
  GET  /api/gwas/variant/{variant}           → GWAS data for variant

COMPREHENSIVE (NEW):
  POST /api/comprehensive/analyze            → All datasets at once
  POST /api/comprehensive/variant-disease    → Full pathway analysis
