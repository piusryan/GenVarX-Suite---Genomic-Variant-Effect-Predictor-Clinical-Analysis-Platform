========================================================
GenVarX Suite - HOW TO RUN
========================================================

STEP 1: Open TWO Command Prompt (cmd) windows.

========================================================
WINDOW 1 - BACKEND (FastAPI on port 8000)
========================================================
Copy and paste these commands one by one:

cd C:\Users\Administrator\Desktop\minini porjsem3\BIOMETRICS\genvarx-suite-main
.venv\Scripts\activate
pip install -r requirements.txt
uvicorn app.main:app --port 8000 --reload

Expected output:
  INFO: Uvicorn running on http://127.0.0.1:8000
  INFO: Application startup complete

KEEP THIS WINDOW OPEN.

========================================================
WINDOW 2 - FRONTEND (React/Vite on port 5173)
========================================================
Copy and paste these commands one by one:

cd C:\Users\Administrator\Desktop\minini porjsem3\BIOMETRICS\genvarx-suite-main
npm install
npm run dev

Expected output:
  VITE ready
  Local: http://localhost:5173/

KEEP THIS WINDOW OPEN.

========================================================
STEP 3 - OPEN IN BROWSER
========================================================
Open your browser and go to:

http://localhost:5173

========================================================
STEP 4 - VERIFY EVERYTHING WORKS
========================================================
Test a variant. Example to type in the search box:

17:43044295:G:A    (BRCA1 example)

========================================================
TROUBLESHOOTING
========================================================
Backend won't start (port 8000 in use):
  netstat -ano | findstr :8000
  Then try: uvicorn app.main:app --port 8001 --reload
  And change .env.local to: VITE_API_BASE_URL=http://127.0.0.1:8001

Frontend won't start:
  npm install
  npm run dev

CORS / Cannot reach backend:
  cat .env.local
  Should have: VITE_API_BASE_URL=http://127.0.0.1:8000

To stop servers: press Ctrl+C in each window.
